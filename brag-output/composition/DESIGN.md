# PhotoTrace brag visual identity

## Style prompt
A calm desktop field tool: green route lines, map pins, white surfaces, and precise typographic labels on a pale green canvas. Motion is purposeful and supports the photo-to-place story.

## Colors
- Canvas: #f3f7f5
- Surface: #ffffff
- Primary text: #18352b
- Accent: #176b4d
- Highlight: #dff1e8
- Border: #b9cbc2

## Typography
Segoe UI for both display and interface text, matching PhotoTrace's Qt stylesheet.

## What not to do
- No generic software growth claims.
- No real user photo or GPS data.
- No remote assets or hosted rendering.
- No fast flashing copy or cluttered feature cards.
